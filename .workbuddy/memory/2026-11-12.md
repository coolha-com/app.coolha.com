# 2026-11-12

## Waffo 测试模式 webhook：读官方文档 → 发现旧结论错误 → 端到端打通

### 用户给的线索
`https://docs.waffo.ai/zh/features/test-mode#测试-webhooks`
（上一轮遗留问题：「webhook 怎么用、环境怎么配」，以及我上一轮写下的
「一个环境只能填一个 URL，TEST 与 PROD 会互相覆盖」这个结论。）

### 结论修正（我上一轮写错了）
用 SDK `@waffo/pancake-ts@0.28.0` 实测 + 读 SDK 类型定义 + GraphQL introspection 确认：

- webhook 是**独立条目**（`store_webhooks` 表），每条带自己的 `testMode` 布尔标志。
  **同一个 store 可以并存多条** `channel=http` 的条目（实测 `webhooks.add` 同 store
  再加一条 `testMode=true` 成功）。所以**「一个环境只能一个 URL」是错的**。
- 列表只有 GraphQL 一个入口：`Store.storeWebhooks`（无 REST 列表接口）。
- `channel` 与 `testMode` 在 update 时**不可变**（SDK 明确说明）→ 改环境只能新建条目。
- 真正的坑是**验签用哪把公钥**，不是 URL 数量。

### 验签方案（定案）
SDK `verifyWebhook` 实测源码行为：
- 传 `options.environment` → **只用那把公钥**，另一把完全不试。
- **不传** → 先试 prod 公钥，失败再试 test 公钥，两把都不过才抛错。

因此：
- `src/lib/waffo/client.ts` 的 `getWaffoWebhookVerifyOptions()` **不再指定 environment**
  → 同一份代码同时认沙箱与正式签名，**同一个 URL 能同时收两种投递**。
- 但**发放授权必须按事件自身 `mode` 判定**（`src/app/webhook/route.ts` 新增
  `environment_mismatch` 分支）：生产部署收到沙箱事件 → 记档、返 200、不发放
  （否则沙箱支付能白嫖正式服务）。返 200 而非 4xx/5xx 是为了不触发 Waffo 重投。

### 公钥（省掉了一个手工步骤）
用密码学方式（SPKI DER 比对）验证：
`env 里的 WAFFO_WEBHOOK_TEST_PUBLIC_KEY` **==** SDK 内置 `TEST_PUBLIC_KEY`
→ 平台**从未轮换** webhook key → **SDK 内置 `PROD_PUBLIC_KEY` 就是当前生产公钥**。

于是 `scripts/gen-env-files.mjs` 自动把两把公钥填进全部 env 文件
（生产公钥**压成单行**，否则会被 .env 解析器截断 → 验签 100% 失败），
再 `sync-vercel-env.mjs` 同步到三档环境。**生产公钥不用再从 Dashboard 手工复制。**

### 根因（为什么之前「支付成功但订单不核销」）
沙箱 webhook 原先指向 `https://app.coolha.com/webhook`，但**生产域名跑 main 分支，
上面没有 `/webhook` 路由** → Waffo 投递拿到 200，但响应体是 HTML 首页，
事件**根本没进我们的处理逻辑**。
实测证据：投递记录 `status=success, http=200`，`responseBody` 是 `<!DOCTYPE html>...`。
→ 已把沙箱条目改指预览部署 `https://appcoolhacom-git-agent-coolha.vercel.app/webhook`。

### 本地开发怎么填 webhook 路由（用户明确问的）
三场景，写进 `docs/WAFFO_INTEGRATION.md` §4.2：
- **A（推荐）**：沙箱 webhook → **预览部署**。本地与预览**同一个 dev 库**，
  订单核销/授权结果本地刷新就看到，**不需要隧道**。
- **B**：要调本地回调逻辑 → ngrok/cloudflared + `add-test` **另加一条**
  （实测可并存，不必改原来的；**别用 localtunnel**，它剥 `X-Waffo-Signature`）。
- **C**：只验证额度/付费墙 → `POST /api/agents/credits/test-grant`（免收银台）。
A 与 B 可同时开，看 `webhookDeliveries` 里对应 URL 的 httpStatus 区分谁处理了。

**两个大坑（务必记住）**
1. **Vercel CLI 64 默认存 Secret**：`vercel env add` 不加 `--type config` 就是 Secret → Dashboard 与 `env pull` 都是 `[SENSITIVE]`，**写进去读不出来**，只能覆盖。DB 连接串这类以后要核对的值必须 `--type config`。另：CLI 64 没有 `vercel env get`；REST API `?decrypt=true` 对 sensitive 类型返回空值（user token 无解密权）。凭据文件在 `%APPDATA%\com.vercel.cli\Data\auth.json`。
2. **禁止用 `echo 值 | vercel env add`**：PowerShell 管道给 stdin 加 UTF-8 BOM（U+FEFF，charCode 65279），连接串/密钥首字符被污染 → 直接失效，且 Secret 类型无法回读验证。必须用 `vercel env add NAME production --value "值"`（`cmd /c` 被安全策略禁用）。

## AI Gateway 401 根因 + 三个真实缺陷（2026-10-16）

**根因**：`.env.local`（Next 所有模式都加载的基线）**根本没有 `AI_GATEWAY_API_KEY`** —— 之前只在三个 `.env.*.local` 镜像里有。加上后发现那把 key（`vck_0YRLEI…`）本身也已失效：curl 直连 `https://ai-gateway.vercel.sh/v1/models` 返回 401 + `Authentication failed. Create an API key…`。DB 里 470 个模型的快照是 2026-10-16T04:11 最后一次成功同步的，所以页面还能显示 67 个赞助模型（陈旧快照兜底），但运行时会持续尝试回源并失败。

**顺带修掉三个真实缺陷**（都是这次 401 暴露出来的）：
1. **失败无退避 → 每次渲染都重打上游并刷一条 error**。`synced_at` 失败时不推进 → 快照永远「不新鲜」→ `/chat` 每次渲染都重新 fetch 上游。修法：迁移 `009_catalog_sync_backoff.sql` 加 `failed_at` 列，失败时写入、成功时清空；`client.ts` 在认领锁前判定窗口（凭证类 401/403 用 300s，其他 300s），窗口内直接复用陈旧快照。**force=true（`/api/v1/models?refresh=1`）跳过退避**，key 轮换后可立即生效。
2. **退避判定不能用 Data Cache**（踩坑）：`readCachedCatalogSnapshot` 走 `unstable_cache`（TTL 3600s），缓存里是**失败发生前**的快照，`failed_at` 为空 → 判定永远不成立，退避形同虚设（实测仍打 5 条日志）。修法：新增 `readCatalogSyncMeta()` **不走 Data Cache**，只读那一行元信息。改完实测 6 次请求只打 1 条日志。
3. **Next.js 控制流信号被误当故障吞掉**：`DYNAMIC_SERVER_USAGE`（`digest === "DYNAMIC_SERVER_USAGE"`，见 `next/dist/client/components/hooks-server-context.js`）是框架中断静态预渲染改走动态渲染的内部信号，被 catch 吞掉后 `last_error` 被写成一条与网关无关的构建错误、**掩盖真正的 401**，且 `failed_at` 被置位触发错误退避。修法：`isNextControlFlowSignal()` 识别后原样重抛（并先 `releaseCatalogSync(false, {error:"RENDER_ABORTED"})` 释放锁，否则锁被按住 120s）；`isRealGatewayFailure()` 把 `RENDER_ABORTED`/`SYNC_IN_PROGRESS` 排除在「真实故障」外。

**可观测性补强**：`/api/health` 原来只检查 `AI_GATEWAY_API_KEY` **是否存在**（不验证可用），key 失效时仍报 ok。现在读 `model_catalog_sync` 的 `last_error/failed_at/model_count`，回源失败时 `aiGateway.ok=false`、`freeModels.ok=false`、顶层 `degraded=true` 且 HTTP 503。实测输出：`已配置但回源失败：UPSTREAM_401（470 个模型仍由陈旧快照兜底）`。

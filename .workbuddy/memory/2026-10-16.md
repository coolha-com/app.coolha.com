**两个大坑（务必记住）**
1. **Vercel CLI 64 默认存 Secret**：`vercel env add` 不加 `--type config` 就是 Secret → Dashboard 与 `env pull` 都是 `[SENSITIVE]`，**写进去读不出来**，只能覆盖。DB 连接串这类以后要核对的值必须 `--type config`。另：CLI 64 没有 `vercel env get`；REST API `?decrypt=true` 对 sensitive 类型返回空值（user token 无解密权）。凭据文件在 `%APPDATA%\com.vercel.cli\Data\auth.json`。
2. **禁止用 `echo 值 | vercel env add`**：PowerShell 管道给 stdin 加 UTF-8 BOM（U+FEFF，charCode 65279），连接串/密钥首字符被污染 → 直接失效，且 Secret 类型无法回读验证。必须用 `vercel env add NAME production --value "值"`（`cmd /c` 被安全策略禁用）。

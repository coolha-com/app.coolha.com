## 统一鉴权 + 身份/计费架构决策（ADR：docs/ARCHITECTURE_IDENTITY_BILLING.md）

- 用户三问：① 连接+签名能统一吗 ② 唯一 ID 是地址吗 ③ 计费地址独立。
- 落地：`@reown/appkit-siwe@1.8.24`（与 appkit 1.8.24 精确匹配）+ `src/config/siwe.ts`（createSIWEConfig 四回调桥接自建 /api/wallet-auth/* 路由）→ Wagmi_Provider createAppKit 传 `siweConfig`（required:false 取消签名不断链）。**AppKit 弹窗内一步完成连接+签名；社交登录自动建嵌入式钱包并无感签名**。统一流程/侧边栏按钮/未来 API Key 共用同一会话源。
- 决策：唯一 ID = 内部 user_id（Phase 3 建 users+user_identities），EVM 地址是身份锚点可多个；计费地址与身份地址分离（余额挂 user_id，充值=订单引用+幂等账本）。
- 坑：appkit 1.8.24 的 `ReownAuthentication`（来自 appkit-siwx）是 Reown 云托管会话，不符合自建后端目标——自建后端要用 appkit-siwe 的 createSIWEConfig；appkit-siwx/lit 已试装后卸载。
- 验证：tsc 0 errors、lint 0 errors、build ✓（含 siweConfig）、dev 热更新 200。

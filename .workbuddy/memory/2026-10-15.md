# 2026-10-15

## 算力市场商业模式合规调研（Vercel AI Gateway 能否做中转站/算力中间商）

结论：**技术上可行，合同上基本堵死**。已核实 Vercel 官方条款原文（ToS / AUP 2026-04-21 / AI Product Terms 2026-03-31）。

### 三道闸门
1. Vercel ToS §11(i)(iv)：不得 sublicense/resell/rent/lease/transfer/commercially exploit 或把 Services 提供给第三方；不得用于 timesharing / service bureau。
2. Vercel AUP（2026-04-21）：禁止 "Rent, lease, loan, or sell access to, or otherwise transfer/make the Services available to any third party"；AI Services 专章禁止 "Buy, sell or transfer Vercel's third-party AI providers' API keys from, to or with a third party"；禁止用 Services 开发 "similar or competing product or service"。
3. AI Product Terms §2：许可 non-transferable、无 sublicense 权、solely for Customer's **personal or internal business use**。§10.2 Credits 不可转让/出售。

### 唯一合法出口
AI Product Terms §8.3：可提供自有 Application 让 End User 通过它与 AI Gateway 交互，条件是给 End User 独立 ToS + 隐私政策、提前披露使用 AI、End User 也须遵守 AI Product Terms、并对 Vercel 承担 indemnity。
→ 界限：**卖 token = 违规；卖产品/能力 = 允许**。

### 上游同样禁止（差价模式不成立）
- AI Gateway zero markup（provider list price pass-through，BYOK 也不加价）→ Gateway 层不产生任何批发差价。
- OpenAI Services Agreement §3.1/§3.3：不得 resell/lease 账户访问、不得买卖转让 API keys。
- Anthropic Commercial Terms：不得 resell the Services（除非明确批准）、不得建竞品。
- OpenRouter ToS §7：禁止 "reselling API access to Models or ... developing a competing service"。
- 上游公开合法折扣只有 batch 50% / cache 10% / 模型降级，无批发价可转嫁；市面 70–90% 折扣来自薅免费额度、拆卖订阅号、跨区账号（Anthropic 2026-02 蒸馏报告已点名 commercial proxy services 打击）。

### 对本项目的影响
`/ai` 算力市场若按 "发 API key → 按 token 加价转发" 设计，正好撞 AUP 三连（sell access + transfer provider key + competing product）。
建议改造方向：① 自有 AI 应用卖能力（推荐，合规、毛利高）；② BYOK 软件层（风险最低，用户自带上游 key）；③ 真做中间商须绕开托管层，与上游签正式转售/Enterprise 协议或自部署开源模型。
另注：`proxy.ts` 地理屏蔽 + 上游 supported-countries 条款叠加，跨境供给风险需单独评估。

# 算力市场上游模型供应商接入方案

> 回应「怎么做腾讯代理商 / DeepSeek / 国内低价算力供应商」。本文是商务+技术双线方案，技术部分与算力市场 Phase 2-3 对齐。

## 一、架构：三层分离（已具备的根基）

```
用户请求
  → Coolha 服务端 Route Handler（鉴权/限额/计费）
    → AI SDK（streamText / generateText）
      → 网关抽象层
        ├─ Vercel AI Gateway（AI_GATEWAY_API_KEY 已配置）
        ├─ Neon AI Gateway（代码就绪，待开通）
        └─ 直连供应商 Adapter（DeepSeek / 腾讯云 / …）
          → 上游推理 API
```

关键点：AI SDK 的 `model` 参数接受任意 provider 实例，**加上游 = 加一个 adapter + 目录里加几行配置**，不动网关、不动计费、不动前端。

## 二、接入一家上游的标准五步（以 DeepSeek 为例）

1. **商务**：注册账号 → 充值 → **读 ToS 确认允许转售/代理**（DeepSeek 开放 API 个人企业均可直接用，无代理商门槛）。
2. **技术适配**：`npm i @ai-sdk/deepseek`（无官方包时用 `@ai-sdk/openai-compatible` 的 `createOpenAICompatible({ baseURL, apiKey })`）→ 在 `src/lib/compute/providers/` 写一个 adapter（统一接口：查模型 / 发起请求 / 流式 / 用量解析 / 错误转换 / 状态）。
3. **目录注册**：模型 ID、上下文、能力标签、**价格 = 上游成本 × (1 + 加价率)**，写入 `compute_models` + `compute_price_versions`（Phase 3 表）；数据来源标 `provider-reported`。
4. **验证**：真实调用一次 → 核对上游返回的 usage 与费用 → 跑通对账。
5. **上线**：模型广场出现该供应商卡片，Playground 可选，API 网关可路由。

## 三、各类上游的现实路径

| 上游 | 接入方式 | 关键注意 |
|---|---|---|
| DeepSeek | 官方 API 直连，按量付费 | 价格极低，适合做**价格锚点**；确认 ToS 转售条款 |
| 腾讯云（混元 / HAI） | 两条路：① 直连 API；② **签代理商/分销合同**拿折扣价 + 转售授权 | 「代理商」是**商务身份不是技术步骤**：需与腾讯云签合同、可能有业绩承诺；技术上仍是 OpenAI 兼容端点，一个 adapter 搞定 |
| 阿里百炼 | 直连 API | 同上 |
| 硅基流动 / SiliconFlow 等聚合 | 直连 API | 其本身是中转——**重点核实其 ToS 是否允许二次转售**，否则有封号风险 |
| Vercel / Neon AI Gateway | 已有凭证 | 省去多账号管理，但加价空间受限，适合冷启动 |

## 四、合规红线（PRD 4.5 已强调，接入前逐家过一遍）

1. **转售授权**：不是所有 API 都允许转售；中转聚合站尤其要逐家核实。
2. **地域限制**：本项目 `proxy.ts` 硬屏蔽中国大陆——算力市场面向海外售卖、国内供应商采购，是「境外售卖、境内采购」结构，需确认供应商是否允许境外 IP 调用与外币结算。
3. **数据处理**：向用户披露请求经过哪些供应商、是否留存 prompt、跨境传输情况。
4. **资金义务**：代收资金、可消费余额、转售第三方 API，可能产生支付、税务、供应商授权方面的义务（PRD 4.7）。
5. **不得伪造**：未签合约/未验证的供应商，不得在目录中标注为已接入。

## 五、建议推进顺序

1. **先接 1 家**（DeepSeek 或直接复用 Vercel AI Gateway 目录），跑通「目录 → 网关 → 计费 → 对账」闭环，验证真实付费需求。
2. **腾讯代理商作为商务线并行**：签约是前提，签约后技术零增量（多一个 adapter）。
3. 供应商 ≥ 3 家后，再做价格比较、延迟路由、故障转移（Phase 3+）。
4. 每新增一家，更新本文的路径表与核验清单。

## 六、商务侧自查清单（签约前）

- [ ] 折扣价 vs 官方价的加价空间是否覆盖支付+基础设施+客服成本
- [ ] 结算周期、预付款要求、退款政策
- [ ] SLA / 故障赔偿
- [ ] 是否允许转售、允许的销售地域
- [ ] 数据留存与跨境条款
- [ ] 品牌使用限制（能否在模型广场标注该供应商）
